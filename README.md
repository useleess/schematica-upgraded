# Schematica upgraded

Forge 1.12.2 port of [Schematica Plus](https://github.com/HackerRouter/Schematica-Plus)
(HackerRouter's Litematica-style Schematica for 1.7.10), with extra optimizations and features.

Download: https://modrinth.com/mod/schematica-upgraded

## Building

Requires JDK 8.

    ./gradlew build

The jar is written to `build/libs/`.
