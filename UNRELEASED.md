# Unreleased changes

Collected here until the next release, then used as the GitHub / Modrinth notes.


- **Keeps your Litematica keybinds:** on the first start, Schematica upgraded copies the keybinds from an installed Litematica (`liteconfig/common/litematica.json` or `config/litematica.json`), so you do not have to set them up again. This happens only once; after that, change keybinds in the Schematica upgraded settings.
