# Blocks of newer Minecraft versions that 1.12 does not have, and what loading puts in their place (MissingBlocks).
# Names without a namespace are minecraft:. Targets are flattened 1.13 names from legacy_block_states.txt (the block
# keeps the facing/half/shape... of the file where the target has them), "air", or "!" + a 1.12 state string.
#
# alias <name> <target>  the same block under a newer name: loaded as it is, never reported as missing
# block <name> <target>  the closest 1.12 block
# rule  <from> <to>      replaces the first <from> in a name, tried in this order until a name is known
# rule  <from>           removes the first <from> in a name
#
# Colours, wood types and shapes (stairs, slabs, walls, fences, doors...) not listed here are worked out from the
# name; see MissingBlockGuesses.
